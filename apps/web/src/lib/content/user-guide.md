## 기본 구조

MonkeyBot의 모든 내전 데이터는 Discord 길드별로 분리됩니다. 상단의 길드 선택 메뉴에서 서버를 바꾸면 내전, 경매, 전적, 랭킹과 관리 화면도 해당 길드 기준으로 전환됩니다.

- **내전**: 일반 내전의 모집 마감, 편성, 픽밴과 결과 입력
- **경매**: 10인 또는 20인 경매 내전의 준비, 입찰, 대진과 결과 입력
- **전적**: 길드 내부 사용자의 일반·경매 내전 기록
- **랭킹**: 현재 길드와 시즌을 기준으로 한 포지션별 순위
- **관리**: 길드 운영자 전용 멤버, 설정, 시즌과 감사 로그

> 길드를 변경해도 다른 길드의 운영 상태나 MMR에는 영향을 주지 않습니다.

<div id="getting-started"></div>

## 시작하기

1. Discord에서 MonkeyBot이 설치된 서버에 참여합니다.
2. Discord 계정으로 웹에 로그인합니다.
3. 상단 길드 선택 메뉴에서 작업할 서버를 선택합니다.
4. 처음 접속할 기본 서버는 **내 정보 → 대표 길드**에서 지정합니다.

대표 길드는 `monkeybot.lol`에 접속했을 때 가장 먼저 열리는 길드입니다. 현재 길드는 언제든 상단 메뉴에서 변경할 수 있습니다.

<div id="series"></div>

## 일반 내전

일반 내전은 하나의 시리즈를 중심으로 운영됩니다. BO3 시리즈라면 각 세트의 픽밴과 결과를 기록하되, 목록과 전적에서는 시리즈 전체 결과를 우선 표시합니다.

### 운영 순서

1. 모집을 마감합니다.
2. 웹에서 참가자를 두 팀과 포지션에 배치합니다.
3. 각 세트의 픽과 밴을 입력합니다.
4. 승리 팀과 결과를 확정합니다.
5. 완료된 결과가 길드 전적과 MMR에 반영됩니다.

엔트리 편성과 픽밴을 여러 운영자가 함께 열면 상단의 실시간 편집 상태에서 연결과 저장 상태를 확인할 수 있습니다.

<div id="auction"></div>

## 경매 내전

경매 내전은 참가 인원에 따라 대진 구조가 달라집니다.

| 인원 | 팀 구성   | 대진           |
| ---- | --------- | -------------- |
| 10인 | 2팀 × 5명 | 결승 직행      |
| 20인 | 4팀 × 5명 | 준결승 후 결승 |

### 생성과 규칙

길드의 활성 멤버는 웹 또는 Discord에서 경매 모집을 열 수 있습니다. 모집을 만들 때 결승 BO1/BO3/BO5와 하드 피어리스 여부를 정합니다. 20인 경매는 준결승 BO도 별도로 정하며, 시작한 뒤에는 이 규칙을 바꾸지 않습니다.

### 운영 순서

1. 모집을 마감한 뒤 운영자가 팀장과 팀별 시작 포인트를 설정합니다.
2. 현재 후보를 뽑아 입찰하고, 낙찰 또는 유찰을 처리합니다. 현재 후보와 유찰 후보는 팀 카드로 드래그해 배치할 수 있습니다.
3. 모든 팀의 로스터가 5명씩 채워지면 브래킷 설정 단계로 자동 전환됩니다.
4. 10인 경매는 결승 대진을 확정한 뒤 해당 경기 작업대에서 라인업을 정합니다. 20인 경매는 준결승 대진을 확정한 뒤 중앙 준결승 라인업 단계에서 네 팀, 20명의 포지션을 함께 배치합니다.
5. 20인 경매는 두 준결승의 10인 라인업이 모두 확정되기 전에는 픽밴이나 세트 결과를 입력할 수 없습니다. 10인 경매는 결승 라인업 확정 뒤 바로 해당 경기의 픽밴과 결과를 입력합니다.
6. 준결승과 결승의 세트 결과를 입력하고 토너먼트를 완료합니다.

브래킷은 드래프트가 끝난 뒤에만 열 수 있습니다. 로스터가 완성되기 전에는 다음 단계로 이동할 수 없으며, 링크로 직접 접근해도 드래프트 작업대로 돌아갑니다. 20인 경매는 브래킷 확정 뒤에도 두 준결승 라인업을 모두 확정해야 경기 입력 단계로 넘어갑니다.

### 현재 후보 정보

현재 후보 카드에서는 Discord 프로필, Riot 티어, 모집 시점 MMR과 해당 시즌의 내전 요약을 확인할 수 있습니다. **상세보기**에서는 라인별 MMR, 선호 챔피언, 확정 내전의 주력 챔피언과 최근 게임, 저장된 Riot 요약을 추가로 확인합니다.

이 정보는 후보를 판단하는 참고 자료입니다. 실제 입찰 기준은 경매 시작 시점에 고정된 MMR이며, 상세보기를 열어도 Riot 데이터를 새로 조회하거나 입찰 기준을 바꾸지 않습니다.

## 전적 검색

길드 전적에서는 Discord 이름 또는 Riot ID로 사용자를 검색할 수 있습니다.

검색한 참가자의 포지션별 선호 챔피언도 함께 표시됩니다. 선호 챔피언은 사용자가 직접 지정한 목록이며,
해당 시즌에 실제로 사용한 챔피언 전적과는 별개입니다.

참가자가 연결된 Riot ID 공개를 허용한 경우에는 Discord 사용자와 연결된 모든 Riot ID를 확인할 수
있습니다. 공개를 끈 경우에도 같은 길드의 내전 기록과 MMR은 계속 표시되며, Riot ID 연결 관계만
표시하지 않습니다.

- 일반 내전은 시리즈별 승패와 세트 상세를 표시합니다.
- 10인 경매는 일반 시리즈 형태로 표시합니다.
- 20인 경매는 토너먼트 순위, 팀 로스터와 상대 팀별 시리즈를 함께 표시합니다.
- 세트 상세에서는 포지션, 챔피언, 양 팀 라인업과 밴을 확인할 수 있습니다.

상단 공통 검색에서 **Riot**을 선택하면 외부 Riot 전적을, **Custom**을 선택하면 현재 길드의 내전 전적을 검색합니다.

## 랭킹

랭킹은 현재 길드와 시즌의 포지션별 MMR을 기준으로 집계됩니다. 승률, 경기 수와 선호 챔피언을 함께 확인할 수 있으며 다른 길드의 MMR과 합산되지 않습니다.

## 내 정보

아바타 메뉴의 **내 정보**에서 개인 설정을 관리합니다.

### 선호 챔피언

포지션별로 선호 챔피언을 등록합니다. 편성과 경매에서 참가자 성향을 확인할 때 사용됩니다.

### Riot 계정

Discord 사용자와 Riot ID를 연결하고 대표 계정을 지정합니다. 계정 갱신과 연결 해제도 같은 화면에서 처리합니다.

### 대표 길드

웹 루트에 접속할 때 자동으로 이동할 기본 길드를 지정합니다.

### 개인정보

외부 프로필, Discord 사용자와 연결된 Riot ID의 공개 여부, 길드 밖 사용자의 내전 전적 접근 여부를
설정합니다. 이 설정은 Riot ID 자체의 외부 Riot 전적 검색을 막지 않습니다. 같은 길드의 운영자와
참가자는 길드 운영에 필요한 내전 기록을 계속 확인할 수 있습니다.

## 길드 관리

관리 메뉴는 해당 길드의 운영자에게만 표시됩니다.

- **멤버**: 등록 상태, Riot 연결 상태, 주 포지션 MMR과 활동 상태 확인
- **길드 설정**: 운영자 역할, 모집·엔트리·결과 알림·운영 로그 채널과 외부 공개 설정
- **시즌**: 현재 시즌과 종료된 시즌의 운영 기간 확인
- **감사 로그**: 관리 작업의 실행자, 대상, 시각과 상세 내용 확인

모집 채널은 필수이며, 엔트리·결과 알림·운영 로그 채널은 필요할 때만 설정합니다. MMR 조정에는 실행 사유가 필요합니다. 시즌 전환과 초기화는 Bot 관리자 명령으로만 실행하며 모든 관리 작업은 감사 로그에 기록됩니다.

<div id="realtime"></div>

## 실시간 편집

일반 내전 엔트리 편성, 픽밴, 경매 모집 참가자 명단과 경매 입찰처럼 여러 운영자가 동시에 다루는 화면에는 실시간 편집 상태가 표시될 수 있습니다.

- **연결됨**: 서버와 동기화된 상태
- **저장 중**: 변경 사항을 저장하는 상태
- **충돌**: 다른 운영자의 변경과 겹쳐 최신 데이터를 다시 확인해야 하는 상태

경매 입찰의 실시간 연결은 `BIDDING` 상태의 편집 권한이 있는 운영자에게만 열립니다. 브래킷과 경기 작업대는 HTTP 응답으로 최신 상태를 확인합니다. 연결이 끊겼다가 복구되면 화면은 서버의 최신 원장을 다시 조회하며, 저장되지 않은 로컬 화면을 최종 결과로 간주하지 않습니다.

## 빠른 도구

화면 오른쪽 아래의 빠른 도구에서 내전 운영 중 필요한 보조 기능을 열 수 있습니다.

- 미니게임
- 빠른 전적 검색
- 타이머

빠른 도구는 현재 진행 중인 내전이나 경매 데이터를 직접 변경하지 않습니다.
