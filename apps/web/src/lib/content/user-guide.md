## 기본 구조

MonkeyBot의 모든 내전 데이터는 Discord 길드별로 분리됩니다. 상단의 길드 선택 메뉴에서 서버를 바꾸면 내전, 경매, 전적, 랭킹과 관리 화면도 해당 길드 기준으로 전환됩니다.

- **내전**: 일반 내전의 모집 마감, 편성, 픽밴과 결과 입력
- **경매**: 10인 또는 20인 경매 내전의 준비, 입찰, 대진과 결과 입력
- **전적**: 길드 내부 사용자의 일반·경매 내전 기록
- **랭킹**: 현재 길드와 시즌을 기준으로 한 포지션별 순위
- **관리**: 길드 운영자 전용 멤버, 운영, 설정과 감사 로그

> 길드를 변경해도 다른 길드의 운영 상태나 MMR에는 영향을 주지 않습니다.

<div id="getting-started"></div>

## 시작하기

1. Discord에서 MonkeyBot이 설치된 서버에 참여합니다.
2. Discord 계정으로 웹에 로그인합니다.
3. 상단 길드 선택 메뉴에서 작업할 서버를 선택합니다.
4. 처음 접속할 기본 서버는 **내 정보 → 대표 길드**에서 지정합니다.

대표 길드는 `monkeybot.lol`에 접속했을 때 가장 먼저 열리는 길드입니다. 현재 길드는 언제든 상단 메뉴에서 변경할 수 있습니다.

<div id="series"></div>

## 일반 내전

일반 내전은 하나의 시리즈를 중심으로 운영됩니다. BO3 시리즈라면 각 세트의 픽밴과 결과를 기록하되, 목록과 전적에서는 시리즈 전체 결과를 우선 표시합니다.

### 운영 순서

1. Discord 모집을 마감합니다.
2. 웹에서 참가자를 두 팀과 포지션에 배치합니다.
3. 각 세트의 픽과 밴을 입력합니다.
4. 승리 팀과 결과를 확정합니다.
5. 완료된 결과가 길드 전적과 MMR에 반영됩니다.

편성이나 결과 입력 화면을 여러 운영자가 함께 열면 상단의 실시간 편집 상태에서 접속자와 저장 상태를 확인할 수 있습니다.

<div id="auction"></div>

## 경매 내전

경매 내전은 참가 인원에 따라 대진 구조가 달라집니다.

| 인원 | 팀 구성   | 대진           |
| ---- | --------- | -------------- |
| 10인 | 2팀 × 5명 | 결승 직행      |
| 20인 | 4팀 × 5명 | 준결승 후 결승 |

### 운영 순서

1. 팀장과 팀별 시작 포인트를 설정합니다.
2. 참가자를 입찰하거나 필요한 경우 수동 배치합니다.
3. 20인 경매는 준결승 대진을, 10인 경매는 결승 대진을 확정합니다.
4. 매치 시작 전에 양 팀의 포지션별 라인업을 확정합니다.
5. 세트 결과를 입력하고 토너먼트를 완료합니다.

입찰, 수동 배치와 라인업 복구는 현재 진행 단계에서 지원되는 고정 작업만 사용할 수 있습니다.

## 전적 검색

길드 전적에서는 Discord 이름 또는 Riot ID로 사용자를 검색할 수 있습니다.

- 일반 내전은 시리즈별 승패와 세트 상세를 표시합니다.
- 10인 경매는 일반 시리즈 형태로 표시합니다.
- 20인 경매는 토너먼트 순위, 팀 로스터와 상대 팀별 시리즈를 함께 표시합니다.
- 세트 상세에서는 포지션, 챔피언, 양 팀 라인업과 밴을 확인할 수 있습니다.

상단 공통 검색에서 **Riot**을 선택하면 외부 Riot 전적을, **Custom**을 선택하면 현재 길드의 내전 전적을 검색합니다.

<div id="leaderboard"></div>

## 랭킹

랭킹은 현재 길드와 시즌의 포지션별 MMR을 기준으로 집계됩니다. 승률, 경기 수와 선호 챔피언을 함께 확인할 수 있으며 다른 길드의 MMR과 합산되지 않습니다.

<div id="profile"></div>

## 내 정보

아바타 메뉴의 **내 정보**에서 개인 설정을 관리합니다.

### 선호 챔피언

포지션별로 선호 챔피언을 등록합니다. 편성과 경매에서 참가자 성향을 확인할 때 사용됩니다.

### Riot 계정

Discord 사용자와 Riot ID를 연결하고 대표 계정을 지정합니다. 계정 갱신과 연결 해제도 같은 화면에서 처리합니다.

### 대표 길드

웹 루트에 접속할 때 자동으로 이동할 기본 길드를 지정합니다.

### 개인정보

외부 프로필, 연결된 Riot ID와 외부 전적 검색의 공개 범위를 설정합니다. 같은 길드의 운영자와 참가자는 길드 운영에 필요한 내전 기록을 계속 확인할 수 있습니다.

## 길드 관리

관리 메뉴는 해당 길드의 운영자에게만 표시됩니다.

- **멤버**: 등록 상태, Riot 연결 상태, 주 포지션 MMR과 활동 상태 확인
- **운영**: 최근 복구 지점 확인과 적용
- **길드 설정**: 운영자 역할, 모집·로그 채널, 현재 시즌과 외부 공개 설정
- **감사 로그**: 관리 작업의 실행자, 대상, 시각과 상세 내용 확인

MMR 조정과 복구에는 실행 사유가 필요합니다. 일괄 등록, 시즌 초기화, 오래된 내전 정리는 Bot 관리자 명령으로만 실행하며 모든 관리 작업은 감사 로그에 기록됩니다.

<div id="realtime"></div>

## 실시간 편집

편성, 픽밴, 경매 입찰과 라인업처럼 여러 운영자가 동시에 수정할 수 있는 화면에는 실시간 편집 상태가 표시됩니다.

- **연결됨**: 서버와 동기화된 상태
- **저장 중**: 변경 사항을 저장하는 상태
- **충돌**: 다른 운영자의 변경과 겹쳐 최신 데이터를 다시 확인해야 하는 상태

연결이 끊겼다가 복구되면 화면은 서버의 최신 원장을 다시 조회합니다. 저장되지 않은 로컬 화면을 최종 결과로 간주하지 않습니다.

<div id="tools"></div>

## 빠른 도구

화면 오른쪽 아래의 빠른 도구에서 내전 운영 중 필요한 보조 기능을 열 수 있습니다.

- 미니게임
- 빠른 전적 검색
- 타이머

빠른 도구는 현재 진행 중인 내전이나 경매 데이터를 직접 변경하지 않습니다.
